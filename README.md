# Algerian E-commerce Analysis

This repository contains data analysis and visualizations for Algerian e-commerce delivery and return rates by region and wilaya.

## Contents
- Data cleaning and exploration
- Calculation of delivery times and distances
- Return rate analysis (overall, by wilaya, by region)
- Visualizations (charts, summary tables)
- Export of results to CSV and images

## Structure
- Notebooks: Exploratory Data Analysis (EDA) and visualizations
- Data: Raw and processed CSV files
- Charts: Exported figures (PNG, PDF)

## Usage
1. Clone the repository
2. Open the notebooks in Jupyter or VS Code
3. view directly the analysis or put the dataset in a data folder and run the cells

## Requirements
- Python 3.x
- pandas, numpy, matplotlib, seaborn
